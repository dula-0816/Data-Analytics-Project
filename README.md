# 📊 Data Analytics Project – Retail Sales Data Analysis

## 📌 Project Overview

This project focuses on cleaning, preprocessing, analyzing, and visualizing a retail sales dataset using Python, Pandas, Matplotlib, and SQLite.

The project demonstrates a complete data analytics workflow including:

- Data Cleaning & Preparation
- Exploratory Data Analysis (EDA)
- Data Visualization
- SQL Database Integration & Analysis

The dataset contains customer order information such as:

- Products
- Payment methods
- Shipping details
- Sales values
- Order statuses

---

# 🎯 Objectives

- Identify and handle missing values
- Remove duplicate records
- Standardize date formats
- Perform exploratory data analysis
- Generate business insights using SQL queries
- Visualize product sales trends
